# San Juan Boating Guide

A purpose-built web guide for boaters cruising the San Juan Islands — curated from the dock, not the highway.

Part of [Madrona Product Studio](https://www.madronaproduct.com).

## What it is

Every marina, restaurant, trail, and gallery is a hand-written entry oriented around the dock — drawn from three summers of cruising the San Juans. Marinas list VHF channels, moorage types, fuel availability, and depth cautions. Restaurants list walk distance from the slip. Live enrichment from Google Places keeps photos, ratings, and contact info current.

Content organized by island and by marina across five tabs — Map, Islands, Dining, Trails, Logistics.

## Stack

- Vanilla HTML/CSS/JS with Leaflet for maps
- Google Places API via cached serverless proxies
- Deployed on Vercel

## Status

Live at [sanjuan-guide.vercel.app](https://sanjuan-guide.vercel.app) — shared with cruising boaters for feedback.
